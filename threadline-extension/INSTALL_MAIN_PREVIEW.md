# 研线 main 开发预览版安装指南（UI-D1–D3，2026-10-27）

**当前 main 包含 PR #77–#80 的代码，但没有新的正式 Release。** 适合在独立浏览器配置中用虚构数据试用，不等于真实账号/真人体验通过验收。公开仓库和测试截图中不应包含公司的原始对话、内部结论或个人信息。

## 下载和加载

1. 使用 [main 源码 ZIP](https://github.com/siskosun/ThreadLine/archive/refs/heads/main.zip)；不是 [已发布 v0.8.2 ZIP](https://github.com/siskosun/ThreadLine/releases/download/v0.8.2/ThreadLine-v0.8.2.zip)，后者没有宽页资料库、D2 侧栏减负和 D3 宽页地图。
2. **完整解压**，打开 `ThreadLine-main/threadline-extension`。这个文件夹应直接包含 `manifest.json`、`panel.html`、`library-surface.js` 和 `research-map.js`。
3. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，打开开发者模式并点击“加载已解压的扩展程序”，选择上一步的 **threadline-extension 文件夹**，不要选仓库根目录或旧的 Release 解压目录。
4. 关闭已打开的研线侧栏，重新从**新安装的扩展实例**打开。检查标题下的“UI-D3 开发预览 · main”。基础 `manifest.version` 仍为 `0.8.2`，但扩展详情应显示 `UI-D3 MAIN DEVELOPMENT` 版本名称，避免误判旧包。
5. 原三个主标签仍保留，紧接其下有整行“在宽页打开资料库”；“对话切换 → 全部课题与管理”中的高阶 Fork、备份和网页自检已收进“高级研究与维护工具”；“研究整理”完成某次采集后，可以点击“在宽页查看本次思维导图”。

## 没看到新功能

先看是否有“UI-D3 开发预览 · main”标记。没有表示当前侧栏不来自该版本，优先检查扩展的本地加载路径、是否启用了两个同名扩展、是否重新加载并关闭旧侧栏。检查 `threadline-extension/panel.html` 中的 `id="library-open"` 和 `id="report-open-wide-map"` 可进一步分辨文件版本。

如果顶部有标记但入口仍不显示，请截取侧栏顶部（遮盖真实材料），记录 Edge/Chrome 版本、视口和扩展 ID 后再排查。

## 本地数据安全

- **不要卸载旧扩展、清除旧 ID 的浏览器扩展存储或删除原安装目录**。在不同目录“加载已解压的扩展程序”可能创建另一个扩展 ID，因此新安装看不到旧 ID 的课题数据，不能据此断言原数据已被删除。
- 若考虑升级原 ID，应先理解其存储范围和原有备份：课题关联、结论证据与 Fork 分别有不同范围，导出的课题 JSON **不包含所有临时 IndexedDB 采集全文**。
- UI-D1 宽页的默认行为是查阅，原侧栏继续承担正式采纳/修订、撤回、交接及备份恢复；宽页“只读”是界面约束，不是新增的后台独立授权。

## 已知限制

- AI 深度整理使用实验性 ChatGPT 网页自动发送/回复识别时可能失败，用户实测曾报告“发送结构化提示后无回复”。当前工程候选仅强化了专用网页的可见性、未知结果与不自动重发保护；**没有真实登录端到端证明该问题已经修复**。手动复制提示词后仍需要用户亲自发送。
- 回复“停止生成”提示仅说明识别到网页输出状态变化，不代表模型服务器确认完成，更不代表研究结论已经正式采纳。
- 思维导图是本地采集记录的只读可视化；缓存过期后不会自动恢复或偷换为其他对话。需要重新采集时请主动操作。
- 尚未完成 5 位非设计者＋2 位熟练用户的冻结体验任务、真实登录 ChatGPT 的这轮工作流复测及完整读屏验收；不能将合成 Chromium 自动化检查解释为上述人工验收通过。

如需确认准确代码，打开 [main 提交列表](https://github.com/siskosun/ThreadLine/commits/main/) 查看 HEAD。开发预览版的源码 ZIP 随 main 更新，不会像正式 Release 一样提供固定发行版本或自动更新。
