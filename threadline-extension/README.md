# ThreadLine UI-D1 试用版（PR #78） · 操作说明

**[下载包含宽页入口的 UI-D1 分支 ZIP](https://github.com/siskosun/ThreadLine/archive/refs/heads/feat/ui-d1-library-surface-20261027.zip)** · [安装与旧版辨识说明](INSTALL_UI_D1_PREVIEW.md) · [返回仓库](https://github.com/siskosun/ThreadLine)

> 注意：[正式 v0.8.2 Release 包](https://github.com/siskosun/ThreadLine/releases/download/v0.8.2/ThreadLine-v0.8.2.zip) **没有**宽页入口。如果下载或安装了该 Release 包，无法通过重新加载得到 UI-D1 功能。

## 安装 UI-D1 测试版

下载**本分支** ZIP，完整解压。在 Chrome/Edge 的扩展管理页面启用开发人员模式，选择解压后的 `ThreadLine-feat-ui-d1-library-surface-20261027/threadline-extension` 文件夹（其中直接包含 `manifest.json` 和 `library-surface.js`）。**不要选择以前 v0.8.2 的解压目录**。

正常安装和重新加载后，侧栏标题下应有“UI-D1 试用版 · PR #78”，三个标签下方应有“在宽页打开资料库 ↗”按钮。两个版本基础扩展号都显示 `0.8.2`，不能靠这一字段判断是否装对。若未出现，请检查是否同时启用两个同名研线，并关闭旧侧栏重新打开。

无需 Node、GitHub 插件或本地服务。旧版扩展不要卸载或清数据；不同加载目录可能产生不同扩展 ID，存储也互不共享。请先在独立浏览器配置用虚构材料测试。

从 v0.5.0 升级必须保留原扩展目录路径或先导出备份：保持相同目录升级通常沿用已有扩展 ID。**v0.6.0 未更改 manifest key**，这是为避免在还没准备迁移时改变 ID；扩展 ID 并非跨任意目录固定。

## 1. 对话切换

打开若干 ChatGPT 标签页，点击研线图标。点击“创建临时课题”，再通过“关联当前对话”将同研究的分支加入课题。第一屏显示最新结论、分支和待核对状态。切到其他分支时，可看到具体变化内容，不会只看到不明所以的版本号。

**差异算法边界：** 记录最近 30 条目标/结论/阶段字段变化（按字段记录）；连续空白和常见标点变化不升级知识版本，但实质数字差异会升级。未实现基于分支依赖关系的真正语义冲突判断。对于超过保留范围的旧版本，提示历史有缺失。

## 2. 数据备份

打开“全部课题与管理”，使用“导出 JSON 备份”。下载的 JSON 包含本地课题、关联、版本历史和轻量元数据；**不包含 IndexedDB 暂存的采集全文**。导入前会显示待覆盖的条数并要求确认，旧状态被保存为滚动快照。

“恢复最近快照”可找回前一次核心状态；只保留最近五份。备份可能含内部研究结论，切勿放到公开仓库、网盘或发送给不相关人员。

## 3. 网页兼容性自检

打开“全部课题与管理 → 网页适配自检”，点击检查。此操作只读取当前 ChatGPT 页面的必要控件特征，不发送 AI 请求，不创建项目，也不归档。会标示基本输入框是否检测到，并列出采集、移入和归档**最后一次由扩展确认成功**的时间。未出现时间不等于发生故障；显示“页面可识别”也不等于所有功能已通过真实验收。

## 4. 研究整理

在“研究整理”选择目标对话、点击采集，再选择 ChatGPT 手动分析、实验性网页分析、Ollama 或官方 OpenAI API。结构化总结生成后，可在页面中展开审核卡、编辑候选结论、勾选已核查，并发布到共享课题。AI 不会自行收口。网页项目、移动及归档均作用于本次采集的原始对话；结果不明时保留未核实状态，避免盲目重试。

## 5. 测试

- `npm run verify`：所有 JavaScript 单测、语法、版本一致性检查。
- `python test/send-matrix-smoke.py`：离线发送路径矩阵，不用真实账号。
- `python test/extension-e2e.py`：真正通过 `launch_persistent_context` 加载扩展并测试 Chromium 存储（前提是环境允许加载扩展）。

CI 自动执行 Node 检查和真实扩展加载的**合成页面**测试。系统管理策略禁止扩展安装的环境无法运行后者，应如实记录阻断，不将其等同于测试成功。详细限制参阅 VERIFY.md。
