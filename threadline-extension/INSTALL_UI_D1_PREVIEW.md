# UI-D1 测试版：识别安装版本与宽页资料库入口

本文件只适用于 [PR #78 的 UI-D1 试用分支](https://github.com/siskosun/ThreadLine/pull/78)，并非 main/v0.8.2 正式发行版。候选版的 `manifest.json` 保留基础 `version: 0.8.2`，但 `version_name` 带有 `UI-D1 PREVIEW PR78` 标记；**不能只看版本号 0.8.2** 判断是否加载了新代码。

## 正确安装（Chrome / Edge）

1. 从 [UI-D1 分支 ZIP](https://github.com/siskosun/ThreadLine/archive/refs/heads/feat/ui-d1-library-surface-20261027.zip) 下载并**完整解压**，不要直接加载 ZIP。
2. 在解压目录中找到 `ThreadLine-feat-ui-d1-library-surface-20261027/threadline-extension/manifest.json`。**在扩展管理页选中 `threadline-extension` 文件夹，不是其父目录，也不是此前 v0.8.2 发行包目录。**
3. 打开 Chrome `chrome://extensions` 或 Edge `edge://extensions`，开启开发者模式并点击“加载已解压的扩展程序”。确认选中的解压目录包含当前分支的 `library-surface.js` 和 `panel.html`。
4. 如果已经加载：在扩展管理页找到所加载的那一份研线并点击“重新加载”；**关闭旧侧栏**，再通过刚加载的扩展图标打开侧栏。
5. 目视检查**侧栏顶部**：标题下方必须出现 `UI-D1 试用版 · PR #78`，三个标签页正下方必须有整行的“在宽页打开资料库 ↗”按钮。点击它才会打开独立的资料库标签页；资料库不会自动弹出。
6. 如果没有试用标记：打开扩展管理页核对扩展详情的本地目录，并检查是否同时启用了两个同名“研线”。可能仍打开了旧版扩展（也可能未重新加载）。可以**暂时停用**旧版，再打开试用版排查。不要卸载、清除旧版数据或删除原扩展目录。

## 重要的数据提醒

- UI-D1 当前仍为 Draft，建议仅在独立浏览器配置中使用虚构资料验证。
- 解压到不同文件夹再“加载已解压的扩展程序”可能产生不同扩展 ID，新的扩展看不到旧 ID 下的本地数据；**不代表原数据已丢失**。
- 为保留历史 ID 与数据，不要在不理解存储范围前改动原安装目录或卸载原扩展。旧扩展的备份并非覆盖所有 IndexedDB 采集正文。
- 资料库宽页第一阶段主要用于**查阅**：结论搜索、依据和历史阅读。采纳/修订/撤回、交接和备份恢复仍留在侧栏。
- UI-D1 的可见按钮是普通用户界面入口；不是新建的后台独立授权边界。

## 仍无法看到入口

记录浏览器、扩展管理页中的**解压加载路径**、是否存在多个研线、侧栏顶部截图，以及当前 `threadline-extension/panel.html` 是否包含 `id="library-open"`。截图前请遮盖真实研究内容。

只要当前加载的确实是本分支文件，普通侧栏中 `#library-open` 应出现在三个标签页下方。独立合成 Chromium 回归在 320px 与 360px 视口检查此按钮位于第一屏；仍需真人浏览器复核。
