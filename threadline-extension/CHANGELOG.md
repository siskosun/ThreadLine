# ThreadLine CHANGELOG

## v0.7.0 — Fork 双分支对照 Beta（P2/P3）

- 新增「Fork 双分支对照」第一期能力：冻结共同材料 W₀ 与任务指令 P（SHA-256、canonicalization-v1）、发起双分支（两个独立普通新聊天标签、同一冻结文本预填、永不自动发送）、发送后会话身份持久绑定与重启恢复。
- 人工发送后自动读取真实用户消息并对照冻结文本分类（exact/canonical_equivalent/unverified/differs）；采集完成后以两类独立可检信号判定分支完成。
- X/Y 去标签对照：两分支均完成且输入一致才生成映射；映射为已记录随机种子的纯函数，可独立复算；裁决前不展示 A/B 对应关系，提交裁决（preference/criteria/confidence/notes/decidedAt）后揭盲。
- 自包含 JSON 导出（冻结输入与哈希、分支与全部尝试、种子/映射/裁决）；仅导出，不支持导入。功能默认关闭，独立 IndexedDB 存储，不影响原有课题数据。
- 全程不自动发送、不自动重放：发送按钮点击次数在测试中为代码级断言 0。

## v0.6.1 — 浏览器权限修复与自动发布 — 浏览器权限修复与自动发布
