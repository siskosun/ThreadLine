# ThreadLine CHANGELOG

## v0.6.0 — 数据恢复与可观测性

- 显式 schema v1→v2 幂等迁移；拒绝无法识别的未来数据版本。
- 课题 JSON 导出/导入、覆盖前确认、五份滚动快照与一键回滚。
- 结论与目标变更记录字段前后 diff；常见标点与空白变更不误产生版本。
- 核心课题保存添加 revision 变化保护。
- MV3 采集/网页组织运行标识写入 session；中断结果显式降级。
- 只读网页适配健康探测、最近真实成功时间；无真实数据则明确未知。
- AI 候选结论改为侧栏内人工审核卡。
- 增加版本/语法/数据迁移/备份测试，CI 持久浏览器扩展集成脚本。
- README 加入安装包下载链接与升级/权限边界；根 LICENSE 和第三方 NOTICE。

## v0.5.0 — 跨对话切换首页与版本同步

- 同课题分支跳转；知识版本与人工核对版本、状态提醒和收口保护。
- 研究整理移入第二页；AI 结论经人工确认才能写入共享课题。

## v0.4.1 — ChatGPT 网页分析入口调整

- 默认显示实验性 ChatGPT 网页分析模式，其他模型方式可选。

## v0.4.0 — 网页项目创建/移入与归档

- 加入用户确认的网页项目管理操作，不核实成功时停止重试。

## v0.3.0 及之前 — 分层摘要、采集与临时课题

- 本地临时课题、分支标记、对话采集、分析、交接与思维导图基础功能。
