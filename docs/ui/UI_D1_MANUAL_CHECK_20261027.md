# UI-D1 宽页资料库：独立真人验收卡（2026-10-27）

**状态：NOT_EXECUTED；此文档不是签署或报告。** 本卡执行前先记录准确候选 HEAD SHA（见 PR #78）；正式架构计划在 PR #77，当前 main 仍为三导航原版。仅使用新建的无业务资料 Chromium/Edge 测试配置。不要用现有常用用户配置执行可能修改本地课题的步骤。

## 测试准备

1. 取得 [PR #78 的准确 HEAD](https://github.com/siskosun/ThreadLine/pull/78)，下载该分支源码，解压后在隔离浏览器配置的扩展管理页开启开发者模式，加载含 `manifest.json` 的 `threadline-extension` 文件夹。记录浏览器版本、系统、CSS 视口、参与者匿名代码、操作日期和准确 SHA。
2. 验证安装的是候选分支：研线原侧栏有“在宽页打开资料库 ↗”按钮；导航仍是三个标签页。若没有，记录 **版本不匹配**，不要继续统计时间。
3. 用不含个人或公司材料的虚构课题 A/B、不同来源对话以及标记清晰的结论、条件和依据准备任务。50 条与 200 条任务需预先冻结正确结论 ID、依据原文和检索词。CI 使用 200 条合成 IndexedDB，但**它不会自动产生可用于真人测试的持久配置**。
4. 任务先后顺序在测试开始前交叉安排；操作期间不提示入口、不口头指导。记录任务首次点击、走错入口、求助、放弃、完成时间及实际正确性；不要删除失败样本或随意修改通过门槛。

## 人工操作任务与独立核查

| 任务 | 用户指令 | 必须核查的结果 |
| --- | --- | --- |
| A. 原侧栏短路径 | 从 ChatGPT 当前对话切到同课题另一分支 | 不被迫进入资料库；原三导航和切换工作正常，错误分支为 0 |
| B. 从检索打开宽页 | 在侧栏“证据与交接”选课题 A，输入关键词、选状态筛选，然后打开资料库 | 资料库是独立宽页；课题 A、检索词、筛选同时保留；不改变对话所属课题 |
| C. 结论依据和旧版本 | 在准备好的 50 条库找到指定结论，读出版本 1 的完整正文/适用条件及来源，再查看当前版本 | 不是只找到标题；确实打开正确的原始依据、完整正文与修订版本；记录耗时及误选 |
| D. 大库压力检索 | 在准备好的 200 条库查到指定结论及依据 | 预注册目标：非设计者至少 4/5 在 60 秒内完成，错误来源 0；无符合规模的真人样本则记 NOT_EXECUTED |
| E. 刷新与独立视图 | 资料库选 B 并输入检索词/筛选，刷新；同时再打开另一份 A 的资料库 | 刷新后仍是宽页，B 和查询保留；另一资料库保持 A；不存在全局“最后选中课题”覆盖 |
| F. 来源标签变更 | 从一个已保存的来源对话打开资料库，先尝试返回，再将同一个来源 tab 切到另一对话并重试 | 原有效对话可跳转；变化后拒绝错误来源并显示可持续看到的提示；不可误指另一条对话 |
| G. 返回侧栏与权限 | 宽页点击“打开研线侧栏”；查看课题与依据后返回原侧栏 | 不需要另找新扩展；旧侧栏仍可采纳、修订、撤回、交接；宽页不应展示恢复/删除等危险入口 |
| H. 空/失效课题 | 从已删除或无效课题意图打开资料库，或在无 ChatGPT 来源的状态打开 | 明确让用户选择；不能悄悄回退到另一课题并写入；没有来源时不假装能检查当前 ChatGPT 网页 |

**重要权限边界**：D1 复用受信 `panel.html` 页面，其后台原有权限未变。“宽页只读”是当前正常 UI 的显隐边界，**不是新建的后台只读授权边界**；此轮不让用户在宽页执行数据写入。若下一阶段要开放宽页修改/备份/删除，需要重新评估动作与授权范围。
