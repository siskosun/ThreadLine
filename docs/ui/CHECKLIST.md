# UI 与交互验收清单

配套 [设计标准](../../DESIGN.md)。本清单是体验验收补充，不改写 `PLAN.md` 的正式门禁。每项记录 PASS / FAIL / NOT_EXECUTED / NOT_APPLICABLE，并附范围与证据；不得把未测项当作通过。自动化测试、合成 MV3 页面、实际截图人工检查、真实登录网页操作、真人任务与无障碍验收分别记录，不能相互替代或合并成笼统的通过率。

## 固定记录

记录 commit SHA、工作树是否修改、应用版本、浏览器/系统、设备比例、视口、语言、夹具版本、操作步骤、截图/日志路径、执行者。自动化与真人记录分开。示例材料全部合成，禁止上传真实对话、凭据或研究原文。

## 任务与状态矩阵

| 任务 | 最少检查 | 判定依据 |
| --- | --- | --- |
| 创建与关联 | 无当前对话、未关联对话、已有课题、长名称、同名课题 | 下一步可发现；范围明确；完成后可回到原任务 |
| 整理与采纳 | 无数据、仅片段、完整来源、手动导入、无效 JSON、采纳/取消/同内容重试 | 默认路径清楚；来源限制可见；取消不创建；成功只在保存确认后出现 |
| 结论查找 | 0、1、10、50、200 条；相同前缀；撤回与多版本 | 搜索/筛选结果可解释；完整正文、条件、依据与旧版本可阅读 |
| 编辑 | 仅正文、仅条件、撤回、提交失败、窗口切换、另一窗口修改 | 不清空未编辑字段；不丢草稿；过期结果不覆盖当前数据 |
| 交接 | 预览、编辑、切课题、生成晚返回、复制、人工看过 | 各状态分别记录；材料与课题身份一致；不把复制当发送或理解 |
| 备份与恢复 | 每种包的范围、超过容量、文件读取乱序、无效文件、替换预览、取消、未知结果 | 包含/不包含清楚；目标常驻；未知结果无自动重试 |
| Fork | 默认关闭、启用、冻结 2/3/4 分支、未完成/失败/未知、对照及裁决 | 任务名和进度可识别；实际分支数一致；人工发送与校验细节分层 |
| 注入提示 | 普通对话、旧分支、已收口、用户已有草稿、提示移除/重建 | 不遮挡主要编辑器；焦点合理；不误判成功；真实站点需另行人工验收 |
| 后续 S2–S5 | 上游变化、局部路径、过期复核、AI/Argdown 候选 | 仅在该范围实际进入候选后执行，不能计入现有 main 的通过率 |

每个有写入的操作覆盖：初始、加载、成功、失败、取消、重复点击、迟到响应。危险动作额外覆盖操作目标与实际作用范围一致。

## 视觉与无障碍

- [ ] 320、360、480、768、1280 CSS px：无丢失正文/操作；局部横向图表有明确滚动范围；`overflow-x:hidden` 不作为修复证据。
- [ ] 360×900 首屏能辨认课题/来源、当前任务、主要下一步。高频任务不依赖阅读长段帮助。
- [ ] 长弹窗初始打开时提交、取消和状态区完整可见；正文滚动后动作仍可用，滚动区域可键盘进入且焦点不被遮挡。
- [ ] 逐张以原始分辨率打开截图，记录人工视觉检查与前后差异分类；文件哈希和 DOM 测量不替代看图。生产界面截图与独立参考样张分别标注。
- [ ] 正文、辅助文字、非激活导航符合标准字号；最终颜色组合逐态检查对比度。
- [ ] 每个任务区最多一个主视觉动作；危险操作有清楚范围；标签、边距、圆角、图标符合 token。
- [ ] 所有输入有可见标签，图标有可访问名称，状态信息不只用颜色。
- [ ] 仅键盘可走完核心路径；导航顺序稳定；焦点可见且不被遮挡；弹窗取消后焦点返回合理位置。
- [ ] 200% 文字放大、增加文字间距、减少动画模式可用；另做 320 CSS px 重排，不把两项互相替代。
- [ ] 对至少一个核心流程做实际读屏测试，记录软件/版本；DOM 检查不能替代此项。

## 用户体验效果指标

以下为**首轮试验预设目标**，现状尚无真人数值，不能声称已达标。至少招募 5 位未参与设计的目标用户，使用同一组冻结任务；另请 2 位有使用经验的用户复核回访任务。样本仅用于发现问题，不用于推断总体满意率。

| 指标 | 计算口径 | 首轮目标 |
| --- | --- | --- |
| 首次创建并采纳 | 无帮助完成的人数 / 实际参与人数；单条采纳另按既有 S0a 协议计时 | 至少 4/5 完成；不得降低 PLAN 中 12 次采纳的独立门槛 |
| 找到指定结论与依据 | 50 条冻结数据，从任务出现到正确打开依据；错选单独计数 | 至少 4/5 在 30 秒内完成，错误来源 0 |
| 识别备份范围 | 导出前回答该文件是否包含完整证据及 Fork 原件 | 5/5 回答正确；任何误解先修文案/范围提示 |
| 编辑恢复 | 故意引入保存失败，再完成保存或取消 | 输入丢失 0、错误课题写入 0；每位均能说明当前状态 |
| 阅读版本 | 找到一次指定修订的旧正文和变更原因 | 至少 4/5 在 45 秒内完成 |

耗时用事件日志或录像打点，不用回忆估计。计时从任务提示出现至正确完成；超时、求助和放弃都保留，不删除失败样本。对照现状/新版本时交叉顺序，先冻结正确答案，避免设计者自己当唯一受试者。

性能另录固定机器下 20 次导航、搜索、详情打开的中位数/P95，并明确计时起止、冷热状态及数据量；首个有效基线完成前不宣称提升百分比。自动化点击等待时间不是纯渲染耗时。
