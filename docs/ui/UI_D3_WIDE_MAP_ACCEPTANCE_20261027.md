# UI-D3 候选：采集思维导图移至既有宽页（2026-10-27）

## 动机与边界

用户实装 UI-D1 时报告：“思维导图在狭窄侧栏不方便使用，可考虑只放在宽页”。UI-D2 已将该区域默认折叠，但这还不能解决展开后仍需横向滚动的问题。因此 UI-D3 作为**独立候选切片**，在 PR #79 上增加既有宽页的只读「思维导图」标签；不创建第二种长期浏览器宽页，不改变来源归属/采纳/分析算法/备份/后台权限。

### 已实现的路径

1. 在侧栏**完成一次采集**后，显示“在宽页查看本次思维导图 ↗”，侧栏原有地图区域不再可见，主路径仍可阅读规则提要、逐条审核和接续。原有导图 DOM 保留作兼容，不再默认占据侧栏。
2. 入口固定 `run.id` 并验证 `run.status === done` 与 `run.url` 的保存会话 ID 一致；传给资料库的一次性标签页意图只包含结构化的 `cap_<UUID>`、来源标签 ID /稳定 chat key（若当前来源仍一致）、可选已关联课题。不能使用“当前活动标签”代替采集来源，也不能携带原始对话文本。
3. 同一浏览器窗口优先复用已登记资料库标签。**普通“打开资料库”只聚焦，保留现有位置；明确点击“本次思维导图”才在原标签页切换视图并刷新**。不同窗口互不覆盖，普通手动打开的 `panel.html` 不能被劫持。
4. 宽页只读 `ThreadLineCaptureDB.getRun(id)` 及对应 pages；重新组合已保存的本地提要，AI 结果存在时仍标明“未经独立核实”。独立渲染器被侧栏/宽页共同复用。无新权限、无外部模型请求、无后台写入、无数据迁移。
5. 标签页切换、来源对话导航、过期/清除缓存都不得静默显示另一个 `run.id`；来源不存在时允许看已保存的本地导图，但禁用自动来源操作并标明只读。若缓存已过期，显示明确错误，不从其它采集或最后活动标签偷换内容。

## 测试清单

- Node：导航意图的 run ID 正则、无效参数零副作用、跨标签/跨窗口隔离、登记宽页复用、map 显式切换与失败清理、重载状态只在原标签。
- 合成真实 MV3 Chromium：实际 IndexedDB 写入一个 **虚构** 的已完成采集，侧栏出现“在宽页查看”；宽页看到原始标题/规则节点，缩放/折叠有效；普通宽页入口不重置；再次点击导图不新增标签；更换网页会话后导图不串线；删除原缓存后不伪造可读结果。
- 本 PR 仍需准确最终 HEAD 的 Linux/Windows CI；真实登录 ChatGPT 的自然流程、不同浏览器安装/刷新与至少 5+2 任务验收**未执行**。即使 CI 绿色也不可宣称真人完成，不能修改正式机器表状态。
- 候选新架构不许为了让 UI 绿灯而移除证据采纳、关闭/撤回确认、完整性提醒或系统维护。代码不能自动发送、自动重试或把回答结束等价课题收口。

## 风险与回滚

- 缓存默认 3 天清理；导图是**临时采集衍生阅读**，不是永久证据库。
- 宽页读取和旧侧栏同时使用 `panel.html`，必须复核独立窗口的来源身份、迟到响应与权限边界；导航意图和 sessionStorage 都不提供任何数据写权限。
- 如本人真人复测发现宽页地图不可用，撤回本独立 PR 即恢复 UI-D2 默认折叠地图，不须删除本地数据或更改 IndexedDB schema。不得自动回滚原始研究库。
