## 候选验收（不得由 CI 自证真人结果）

1. 侧栏 320/360/480px 打开后，“对话切换”主操作、同题分支可用；“全部课题与管理”单行 48px 可点击并可键盘展开；展开仅呈现统计/创建/看板；高级工具需明确二次进入，不丢 Fork、备份/自检入口。
2. 选择课题后，默认能读出名称、状态、分支；编辑与分支操作可通过清晰摘要展开，不要求用户浏览所有字段才能跳转目标对话。输入时普通异步刷新不会造成草稿丢失。测试至少 A/B 课题、1/3 条分支以及真实保存/取消/危险操作路径。
3. 资料库从同一窗口多次进出只保留一个标签页，且不改查阅课题、搜索、来源和写入目标；两个不同浏览器窗口仍独立。没有有效注册时不劫持用户手动打开的普通 `panel.html`。
4. 回复标识仅在同一已识别 ChatGPT 对话观察到 `streaming:true → false` 且最后助手文本非空后短暂显示。页面切换、无文本、只有 idle 状态不能假报。确认研究完成仍由用户自己更新分支状态。
5. 网页自动分析明确区分“点击发送”、“成功取得 JSON”和“结果未知”。失败时原 tab 可检查，未二次自动发送；若 ChatGPT 真正无回答，仍应记为**阻塞的真实网站兼容问题**而不是称为已修复。
