# ThreadLine 重建验收矩阵（2026-11-01）

所有用例必须记录精确 commit SHA、浏览器版本、操作步骤、原始日志和结果。真实对话/文件只在本地测试配置使用，不上传公开仓库。

| ID | 场景 | 必须验证 | 失败判定 |
| --- | --- | --- | --- |
| A01 | 100+ 条消息的当前分支 | 消息 ID、角色、顺序、时间、正文和当前分支与原始 API 对照 | 漏消息、重复消息、错误顺序或完整性误报 |
| A02 | 多次 regenerate / 分支 | mapping、parent/children、current_node、替代分支可复算 | 分支被压平、错误归属、循环或断链未标记 |
| A03 | 用户上传附件 | PDF、XLSX、CSV、PNG/JPEG、ZIP 的实际字节、MIME、大小、SHA-256 | 只有文件名/URL、空文件、哈希不一致 |
| A04 | 助手生成文件 | sandbox 文件在可用期间被下载并关联到生成消息 | 文件仅保留临时链接或下载失败却标 saved |
| A05 | sediment/file-service 指针 | sediment://file_*、file-service://file_* 和图像专用指针 | 指针前缀未识别或错误拼接下载路径 |
| A06 | 实时缓存 | 显式开启单对话缓存，生成文件出现后及时写入 IndexedDB | 未开启也采集、跨对话采集、未显示缓存状态 |
| A07 | 过期沙盒 | 对真实旧对话/旧生成文件测试 HTTP 403/404/422 与官方 ZIP 回退 | 过期文件伪装为本地成功，或把接口限制误报为数据完整 |
| A08 | 官方导出 ZIP | 读取外层/内层 ZIP、conversation/file 映射，匹配资产并比较 SHA-256 | 假设固定文件名、未解释匹配失败、只比较成功样本 |
| A09 | 本地 ZIP | 解压后 JSON/Markdown/manifest/资产存在，重算哈希一致 | 文件缺失、路径穿越、ZIP 损坏、清单与文件不一致 |
| A10 | 浏览器重启 | IndexedDB 中消息、Blob、任务队列、部分状态恢复 | 关闭浏览器后内容丢失或重复覆盖 |
| A11 | 存储空间不足 | 配额探测、拒绝写入、保留已保存文件、显示失败资产 | 覆盖旧档案、静默截断或无限重试 |
| A12 | 长历史接续 | 100+ 消息生成 history.md，composer 只预填短提示 | 把完整 transcript 填入 composer |
| A13 | 上下文检索 | 新聊天回答历史早期、中间、末尾的预置问题 | 只能回答末尾内容或声称已读但无法定位 |
| A14 | 文件数量边界 | 1、10、20、21+ 文件；动态探测当前网页限制并分批 | 硬编码 10，或超限仍显示完整上传 |
| A15 | 文件注入 | 通用文件输入、正确 MIME/文件名、实际上传状态 | 误选相机输入、只派发事件就标成功 |
| A16 | 目标页白名单 | 新普通聊天允许；Project、Temporary、旧聊天、未知 URL 拒绝 | 错误目标页注入 |
| A17 | 草稿保护 | 非空 composer、已有文件 chip、用户输入变化时拒绝 | 覆盖或清空用户草稿 |
| A18 | 发送安全 | 检查所有代码路径和真实浏览器操作；发送次数为 0 | 自动点击 Send、自动重发或静默发送 |
| A19 | 源对话删除 | 静态检查无删除按钮、删除函数和 DELETE 请求路径 | 存在任何源对话删除路径 |
| A20 | 权限/隐私 | manifest 权限、日志、网络请求、重定向、跨 tab 身份 | 默认 <all_urls>、外传凭据/正文或跨对话读取 |
| A21 | UX | 320/360/480/768/1280px、键盘、焦点、持续错误、部分/未知状态 | 核心操作不可达、失败信息消失、状态混淆 |
| A22 | 真人任务 | 5 位非设计者 + 2 位熟练用户完成保存、找回、接续任务 | 只用自动化结果宣称 UX 达标 |

## 官方导出对照说明

OpenAI 帮助中心说明官方 ZIP 包含聊天记录和相关数据；具体 ZIP 内部文件结构并非稳定 API。第三方解析器对 2026 格式的描述与用户观察到的文件名存在差异，因此测试必须读取样本实际映射，不硬编码 file_<id>.dat 或 file-<id>.dat 任一形式。

## 真实测试数据保护

- 真实测试使用用户本机隔离 Edge 配置。
- 公开 GitHub 只提交合成 fixture、脱敏日志、测试代码和哈希结果。
- 不提交真实 conversation JSON、附件、ZIP、截图或签名 URL。
- 真实验收记录只写任务范围、成功/失败/unknown、浏览器版本和脱敏结果；不写对话正文。
